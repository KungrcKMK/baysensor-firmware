Bay Sensor

ลงโปรแกรมบอร์ดใหม่ทั้งบอร์ดผ่านสาย USB

ขั้นตอน

1ต่อสายเข้าคอมสาย USB ที่ส่งข้อมูลได้ บอร์ดใช้ไฟจากสาย ไม่ต้องเสียบไฟอื่น
2เปิดหน้านี้ด้วย Chrome หรือ Edge บนคอมพิวเตอร์ (มือถือใช้ไม่ได้)
3กดลงโปรแกรมปุ่มแดงในการ์ด "แบบที่ 1" ด้านล่าง
4เลือกพอร์ตชื่อมักเป็น CP210x, CH340 หรือ USB Serial แล้วกด Connect

ถ้าถามว่าจะล้างข้อมูลในบอร์ดไหม

ไม่ติ๊ก (ปกติ)
ค่าเดิมอยู่ครบ: WiFi ระยะพื้น รหัสบอร์ด รถที่ค้างส่ง · ลงเสร็จใช้งานต่อได้เลย
ติ๊กล้างข้อมูล
ลบทุกอย่าง ต้องตั้ง WiFi และวัดพื้นใหม่ รหัสบอร์ดกับรถที่ค้างส่งหาย · ใช้เมื่อบอร์ดรวนหรือย้ายร้าน
5รอจนขึ้นว่าเสร็จราว 1-2 นาที ห้ามถอดสายระหว่างลง
6ตั้ง WiFi ร้านกด Next ในหน้าต่างเดิม เลือก WiFi (2.4GHz) แล้วใส่รหัส · ปิดหน้าต่างไปแล้ว: กดปุ่มลงโปรแกรมอีกครั้ง เลือกพอร์ตเดิม แล้วกด Configure Wi-Fi
7ติดกลับที่เดิมถอดสาย USB เสียบไฟเลี้ยงเดิม · ถ้าล้างข้อมูล เปิดหน้าเว็บของบอร์ด แล้วกด "วัดพื้น" ตอนช่องว่าง

ช่องตั้ง WiFi ไม่ขึ้น: ถอดสาย เปิดไฟบอร์ด แล้วใช้มือถือต่อ WiFi ชื่อ BaySensor-xxxx (รหัส carcare1234) หน้าตั้งค่าจะเด้งขึ้นเอง

แบบที่ 1 · ใช้กับคอมที่ร้าน (มีกล้อง) · รุ่น —

บอร์ดวัดระยะส่งให้โปรแกรมบนคอม คอมเป็นตัวนับและถ่ายรูป

เบราว์เซอร์นี้ลงโปรแกรมไม่ได้ ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ ต้องเปิดหน้านี้ผ่าน https

หาพอร์ตไม่เจอ

เปลี่ยนสาย USB (สายชาร์จอย่างเดียวใช้ไม่ได้) · ถ้ายังไม่เจอ ให้ติดตั้งไดรเวอร์ CP210x หรือ CH340 ตามชิป USB บนบอร์ด · ถ้าเชื่อมต่อไม่ได้ ให้กดปุ่ม BOOT บนบอร์ดค้างไว้ตอนเริ่มลง

หลังลงเสร็จ (แบบที่ 1) ดูการ์ด "ส่งยอดเข้าระบบกลาง" ในหน้าเว็บของบอร์ด

ยังไม่ใส่รหัสบอร์ดปกติ คอมร้านใส่ให้เองภายในราว 5 นาที

ส่งเข้าระบบได้บอร์ดนับและส่งยอดเองแล้ว

ส่งไม่ได้: …จดข้อความมาบอกผู้ดูแล

บอร์ดที่ติดตั้งแล้ว

ไม่ต้องถอดมาลงที่นี่ บอร์ดอัปเดตเองทาง WiFi ทุกครั้งที่เปิดบอร์ด (ตั้งแต่รุ่น 1.4.2) · แต่ละแบบได้อัปเดตของแบบตัวเองเท่านั้น ไม่สลับกัน
