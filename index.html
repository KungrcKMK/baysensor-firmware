ลงโปรแกรมบอร์ดใหม่ทั้งบอร์ดผ่านสาย USB · รุ่น —

ขั้นตอน

  1. เปิดหน้านี้ด้วย Chrome หรือ Edge บนคอมพิวเตอร์
  2. เสียบสาย USB จากบอร์ดเข้าคอม (ใช้สายที่ส่งข้อมูลได้)
  3. กดปุ่มด้านล่าง แล้วเลือกพอร์ตของบอร์ด
  4. ถ้าถามว่าจะล้างข้อมูลไหม: ติ๊กล้าง = เริ่มใหม่ทั้งหมด (ต้องตั้ง WiFi และวัดพื้นใหม่) · ไม่ติ๊ก = เก็บค่าเดิมไว้
  5. รอจนขึ้นว่าเสร็จ (ราว 1-2 นาที) ห้ามถอดสายระหว่างลง
เบราว์เซอร์นี้ลงโปรแกรมไม่ได้ ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ ต้องเปิดหน้านี้ผ่าน https

หาพอร์ตไม่เจอ

เปลี่ยนสาย USB (สายชาร์จอย่างเดียวใช้ไม่ได้) · ถ้ายังไม่เจอ ให้ติดตั้งไดรเวอร์ CP210x หรือ CH340 ตามชิป USB บนบอร์ด · ถ้าเชื่อมต่อไม่ได้ ให้กดปุ่ม BOOT บนบอร์ดค้างไว้ตอนเริ่มลง

บอร์ดที่ติดตั้งแล้ว

ไม่ต้องถอดมาลงที่นี่ บอร์ดอัปเดตเองทาง WiFi หลัง 20:00 หรือตี 3-5 ตอนช่องว่าง (ตั้งแต่รุ่น 1.4.0)
